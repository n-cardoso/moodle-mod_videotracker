## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Use this repository’s private reporting form: go to the Security tab and select Report a vulnerability. Include a clear description, affected versions, reproduction steps or proof of concept, and any suggested mitigation.

We aim to acknowledge reports within 5 business days and provide a status update at least every 14 days while we investigate.

If we confirm the issue, we will work on a fix and coordinate disclosure with you before publishing details. If we determine that the report is not a security vulnerability, we will explain our assessment. We appreciate responsible disclosure and ask that you do not publicly disclose the issue until a fix or coordinated disclosure is available.
